|---|---:|
| 2026-10-30 | 30 |
| 2026-10-31 | 45 |
| 2026-11-01 | 50 |
| 2026-11-02 | 55 |
| 2026-11-03 | 60 |
| **합계** | **240** |

- DB에 시연 계정 소유로 실제 저장한 행: 계획 1, 할 일 5, 실행 기록 5, 계획 수정 이력 1, 회고 1.
- 가상 규칙 변경 예시: 집중 세션 목표 **60분 → 30분**. 해당 수정 작업은 2026-11-04 수행한 것으로, 시뮬레이션에서 구분하는 2일차와 3일차 사이 과거에 실제 변경한 것은 아니다.
- 변경 전 2일 평균 **(30+45)/2 = 37.5분/일**.
- 변경 후 3일 평균 **(50+55+60)/3 = 55.0분/일**.
- 가상 차이 **+17.5분/일**, 가상 변화율 **+46.7%**.
- 이는 생성자가 택한 임의 값의 산술 비교이며 실제 행동·성과 개선이나 규칙 변경의 효과를 증명하지 않는다.

## 실제 브라우저 스크린샷 (총 8장)

`01-login.png`: 로그인 화면 /
`02-register.png`: 회원가입 화면 /
`03-dashboard.png`: 로그인 후 대시보드 /
`04-plan.png`: 계획 목록 /
`05-tasks.png`: 할 일 목록 /
`06-executions.png`: 실행 기록 목록 /
`07-see.png`: 돌아보기 숫자와 집계 /
`08-revision-history.png`: 계획 수정 이력 모달.

- 로그인/회원가입 화면, 계획·할 일·실행·돌아보기 화면과 수정 이력 모달을 **배포된 앱에 직접 접속한 헤드리스 Chrome**으로 촬영했다.
- 앱의 사용자별 API로 저장 후 `GET /api/plans`, `GET /api/tasks`, `GET /api/executions`, `GET /api/export`, 수정 이력을 대조해 한 계정의 시연 기록만 포함됨을 확인했다.
- 이 테스트는 기존 테스트 A/B 계정의 로그인 상태를 이용하지 않았으므로, 실제 A↔B 간 리소스 ID 직접 접근을 이번 테스트에서 재검증한 것은 아니다.
